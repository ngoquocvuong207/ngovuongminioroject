# Dự Án Tìm Hiểu Kiến Thức Nền Tảng Về Internet & Web

## 📝 Giới Thiệu Dự Án
Dự án này được xây dựng nhằm mục đích củng cố, hệ thống hóa và trình bày một cách chi tiết các khái niệm cơ bản nhất trong thế giới Web. Qua đó giúp người học nắm vững cách thức vận hành của mạng máy tính toàn cầu.

## 🎯 Mục Tiêu Đạt Được
- Làm rõ cấu trúc phân tầng và định nghĩa của 6 khái niệm: **Internet, Web, Website, Trang web, Browser, Server**.
- Thực hành triển khai mã nguồn ứng dụng web lên môi trường hosting miễn phí thông qua dịch vụ **GitHub Pages**.
- Chuẩn hóa cấu trúc tài liệu HTML5 kết hợp CSS nội bộ (Internal CSS) để tối ưu hóa hiển thị.

## 💻 Công Nghệ Sử Dụng
1. **HTML5**: Định hình cấu trúc siêu văn bản, sử dụng các thẻ ngữ nghĩa (Semantic tags) như `<header>`, `<main>`, `<section>`, `<footer>`.
2. **CSS3**: Định dạng giao diện, phối màu hiện đại và tăng trải nghiệm UI/UX cho người dùng.
3. **JavaScript**: Xử lý sự kiện tương tác (`Click Event`) khi người dùng tương tác với nút bấm trên trang.

## 🚀 Cách Kiểm Tra Trang Web Chạy Thực Tế
Vui lòng truy cập vào đường link GitHub Pages đã được cấu hình trong phần cài đặt của Repository này để xem kết quả hiển thị trực quan.
